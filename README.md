# Tdraw - Terminal drawing tools

------

基于Rust TUI的简单终端绘图程序，灵感来自于excalidraw。

### 核心功能

仅需使用键盘按键来实现绘图，文本，区块移动等的图表绘制工作：

- 开启程序后，在终端打开不透明的白色画布，占满整个终端，根据终端大小自适应，并监听键盘的按键输入，并在画布中央显示黑色圆点作为光标，通过`w(上),a(左),s(下),d(右)`控制光标的移动
- `ctrl+q`退出程序，`q`是取消键，`enter`是确认键；文字输入模式中 `q` 为普通文字，使用 `Esc` 取消

- `ctrl+d`开启绘画功能，以光标作为定点，通过`w,a,s,d`控制对角定点的位置绘制正方形，`enter`确认位置，结束一次绘画,并保存在本地的`rects.json中`，格式举例：

```json
[
    {
        "x":58,
        "y":24,
        "z":0,
        "width":46,
        "height":10,
        "text":"区块文字"
    },
    ....
]
```



> [!IMPORTANT]
>
> 绘制的内容称作"区块"，实线，目前只有正方形但是后续会拓展，每次绘制的区块有高度的区别

- 光标移动进入正方形边界时边框颜色改变，`z`值高度越高优先度越高，按下`enter`选中，通过`w,a,s,d`移动，在此按下`enter`确定新的位置（不改变原来的高度）
- 选中区块后，按下 `r` 开始输入文字（已有文字时从末尾继续编辑），文字显示在方框内部。内容超出内部宽高时，方框按字符的终端显示宽度自动向右、向下扩展，支持中文，左上角和 `z` 不变；删除文字不会自动缩小方框。
  - `Enter` 确认文字和当前区块位置，保存到 `rects.json` 并结束选择；`Ctrl+J` 换行；`Backspace` 删除末尾一个字素（如带组合音标的字符）。
  - `Esc` 放弃本次文字和尺寸修改，返回选中状态；`Ctrl+Q` 取消所有未确认操作并退出。
  - 输入时 `q/w/a/s/d/r/m/l/k` 均为普通文字，不触发取消、移动或菜单。
  - JSON 新增可选 `text` 字段；旧文件缺少该字段时按空文字加载。超出终端的内容裁剪显示，不限制区块实际尺寸。
- 普通模式下，光标在方框可见边界时按 `l` 固定连线起点，或按 `k` 固定有向箭头起点。随后 WASD 自由移动光标，不移动方框，实时预览连接；到另一个方框可见边界按 `Enter`（或再次按 `l` / `k` 对应键）完成并立即保存，自动退出连线模式。
  - 连线过程中再按对应的 `l` / `k`，如果当前位置不是另一个方框的可见边界，就记录一个中间点，保持连线模式，可连续添加多个点。预览用 `◆` 标记已记录点，路径依次经过这些点，自动补齐水平/垂直折段；连续重复同一点不重复记录。`Enter` 只确认目标方框，不添加中间点。
  - 中间点按画布绝对坐标保存，移动方框时中间点不动，两端仍自动跟随。取消连线会放弃本次所有中间点。
  - 箭头方向为第一个方框 → 第二个方框；`q` / `Esc` 取消，`Ctrl+Q` 放弃未确认连接并退出。
  - 方框内部、空白处、同一个方框不能作为终点；重叠时只命中最高层可见方框的边界。
  - 连线使用圆角正交折线，普通转弯显示为 `╭╮╰╯`，仅真正交叉处显示交叉符号；重复点和共线段不会产生伪十字。端点绑定边及相对位置，移动方框或文字扩展尺寸时自动更新；取消移动/文字编辑时连接同步还原。删除方框同时清理关联连接。
  - 连接保存在起点区块的可选 `connections` 字段中，与方框一起写入 `rects.json`，兼容旧文件。详细格式见 [USAGE.md](USAGE.md)。
- 普通模式下，将光标移到方框外的可见连线或箭头（包括箭头头部）上，连接变蓝；按 `Enter` 选中后变紫，按 `Backspace` / `Delete` 仅删除该连接并立即保存，不删除两端方框。`q` / `Esc` / `Enter` 取消选择，WASD 只移动光标、不移动连接。
  - 方框边界或内部优先选择方框；被方框遮挡的线段不可选。连线交叉或重叠时，优先选择绘制顺序最上层的连接。
- 选中区块后，按下`backspace`删除按键来删除区块，暂时禁用`crtl+z`的撤回
- 选中区块后，按下`m`在光标的右边打开一个功能菜单（menu），详细功能后续再设计，先可以临时写上`上移一层，下移一层，水平翻转，垂直翻转`内容看一下效果，但是不写实际功能；打开menu后，锁住`w,a,s,d`，通过`w,s`上下移动选择menu选项，使用`q`退出或者`enter`确认选项后恢复`w,a,s,d`的移动功能
